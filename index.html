WHY READONLY?

Finding만으로 부족한 이유

예: EC2.2가 실패했다는 사실만으로 Default SG 규칙을 지워도 되는지는 알 수 없습니다. 실제 연결 ENI와 서비스 소유자를 읽어야 합니다.

Finding 소스: Security Hub CSPM 실시간 조회 또는 CIS 보고서 CSV/JSON 업로드. 보고서만 있으면 실패 목록은 볼 수 있지만 최신 연결관계와 비용은 추정치입니다.

ReadOnly AWS 계정 연결

STS AssumeRole. Access Key를 브라우저에 저장하지 않습니다.

  • Security Hub Finding 자동 수집
  • EC2/ENI/SG/RDS/S3/CloudTrail 의존성 조회
  • CloudWatch 사용량 확인
  • 비용은 Cost Explorer/리소스 구성 기반으로 확장

CIS Finding 자동 수집에는 대상 리전의 Security Hub CSPM + 해당 CIS 표준 활성화가 필요합니다.
